# HortiGestão

Sistema para organizar e controlar os clientes a receber de um hortifruti.
O primeiro módulo é a **caderneta de fiado**, feita para uso real no Pilão Hortifruti.

## Problema

O fiado é anotado num caderno no balcão. Ao riscar o que foi pago, o histórico se perde:
não dá para saber quando o cliente comprou, quando pagou, nem conferir o valor.
O caderno rasga, as folhas caem e, no fechamento da semana, nada bate.
O resultado são valores perdidos e clientes desconfiados da anotação.

## Como vai funcionar

- Durante a semana, as compras são anotadas na ficha física de cada cliente, no balcão.
- No sábado, as fichas são digitadas no sistema.
- Na segunda, as fichas voltam impressas e atualizadas, com o saldo de cada cliente.
